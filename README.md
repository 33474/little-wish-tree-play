# 心愿树 · 联机测试版

左右旋转、上下浏览、双击切换远近。使用已有模型，或输入试玩口令后调用 Meshy 真实生成装饰，再写贺卡并拖到挂点上。礼物和回应由 Cloudflare Worker + D1 共享。

不使用 R2，不需要开通模型存储订阅。新生成模型使用 Meshy 临时资源，按最多3天的短期测试使用，请及时下载备份。每个浏览器身份最多生成两次，项目月预算1000积分。清理浏览器身份会失去本人的作者权限，请保留当前浏览器数据。

密钥与试玩口令仅在 Worker Secrets 中，公开仓库不含密钥或口令。后台地址由 public/backend.json 配置。

本地运行：npm ci && npm run dev。main 分支提交后由 GitHub Actions 自动构建和发布前端。
